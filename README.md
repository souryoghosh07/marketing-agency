## ⚡️ 30-Second Quickstart

**Prerequisites:** 
- An API key for your chosen model (e.g., `ANTHROPIC_API_KEY` or `OPENAI_API_KEY`). **Note:** This project operates on a BYOK (Bring Your Own Key) model. You pay only for your own API usage.
- One of the supported CLI runtimes installed (e.g., `agy`, `claude`, `openclaw`).

```bash
git clone https://github.com/yourname/marketing-agency.git
cd marketing-agency

# 1. Initialize templates and environment (sets up .env and active_brief.md)
make init

# 2. (Optional) Run the built-in devtool SaaS demo
make demo

# 3. Or, run against your code or manually written brief
make extract    # (Optional) Auto-generate brief from your local codebase
make run        # Runs research -> strategy -> copy pipeline
```

## 🏗 System Architecture & Information Flow

The pipeline operates strictly as a sequential, file-based pipeline. Every agent reads its predecessor's output artifact directly from the workspace and commits a structured deliverable to the `/output` directory.

```text
[Local Codebase & User Input]
         │
         ▼
┌──────────────────────────────────────────────┐
│ Agent 00: Context Extractor & Brief Generator│
│ (Scans repo codebase to auto-generate brief) │
└──────────────────────────────────────────────┘
         │
         ▼ (Writes: context/active_brief.md)
┌──────────────────────────────────────────────┐
│ Agent 01: Adversarial Researcher             │
│ (Scrapes SERPs, reviews, incumbent pricing)  │
└──────────────────────────────────────────────┘
         │
         ▼ (Writes: output/01_competitor_matrix.md)
┌──────────────────────────────────────────────┐
│ Agent 02: Positioning Strategist             │
│ (April Dunford category framing & wedges)    │
└──────────────────────────────────────────────┘
         │
         ▼ (Writes: output/02_gtm_strategy.md)
┌──────────────────────────────────────────────┐
│ Agent 03: Copy Architect                     │
│ (Generates deploy-ready landing copy & posts)│
└──────────────────────────────────────────────┘
         │
         ▼ (Writes: output/03_launch_pack/*.md)
```

**Note on Agent 00:** Agent 00 is an optional pre-step. If you do not want to manually write `context/active_brief.md`, you can point Agent 00 at your local Git repository. It will inspect your codebase architecture and auto-generate the active brief artifact for the rest of the swarm to consume. Trigger this by running `make extract` before running `make run`.

## 📦 Output Artifacts & Previews

Each agent writes a concrete deliverable into the workspace:

1. `context/active_brief.md`: The synthesized product parameters (manual or auto-generated by Agent 00).
2. `output/01_competitor_matrix.md`: Pricing traps, Reddit/G2 complaints, and incumbent moats.
3. `output/02_gtm_strategy.md`: Positioning wedge, value anchors, and anti-positioning rules.
4. `output/03_launch_pack/`: 
   - `landing_page.md`: Hero, feature transformation, and objection FAQ copy.
   - `show_hn.md`: Technical, authentic launch pitch.
   - `x_thread.md`: High-signal 5-tweet sequence.

## 🔌 Multi-Runtime Compatibility

This project is built to be runtime-agnostic. 

- **Antigravity CLI (`agy`)**
  Ensure `agy` has file system and browser tools enabled via its config. 
  Run: `bash runtimes/agy/run.sh`
- **Claude Code**
  Run the `claude` CLI in the project root. The repository's `CLAUDE.md` automatically registers the slash commands.
  Run: `/agency` to execute the full swarm.
- **OpenClaw**
  Link the skill into your OpenClaw directory: 
  `openclaw skills link ./runtimes/openclaw/skills/marketing-agency`
  Then trigger via chat ops: `/run marketing-agency ./context/active_brief.md`
- **OpenAI Codex**
  Run the provided bash wrapper:
  `bash runtimes/codex/codex_runner.sh`
