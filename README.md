## ⚡️ 30-Second Quickstart

**Prerequisites:** 
- An API key for your chosen model (e.g., `ANTHROPIC_API_KEY` or `OPENAI_API_KEY`). **Note:** This project operates on a BYOK (Bring Your Own Key) model. You pay only for your own API usage.
- One of the supported CLI runtimes installed (e.g., `agy`, `claude`, `codex`, `openclaw`).

```bash
git clone https://github.com/souryoghosh07/marketing-agency.git
cd marketing-agency

# 1. Initialise templates and environment (sets up .env and active_brief.md)
make init

# 2. (Optional) Run the built-in devtool SaaS demo
make demo

# 3. Or, run against your code or manually written brief
make extract    # (Optional) Auto-generate brief from your local codebase
make run        # Runs research -> strategy -> copy pipeline
```

## 🏗 System Architecture & Information Flow

The pipeline operates strictly as a sequential, file-based pipeline. Every agent reads its predecessor's output artifact directly from the workspace and commits a structured deliverable directly to the workspace root.

```text
swarm-agency/
├── skills/                           # Atomic, standardized Agent Skills
│   ├── brief-generator/
│   │   └── SKILL.md
│   ├── adversarial-research/
│   │   └── SKILL.md
│   ├── positioning-strategy/
│   │   └── SKILL.md
│   └── launch-copy/
│       └── SKILL.md
├── workflows/                        # Orchestration chains
│   ├── run_full_agency.sh            # Chains the skills sequentially
│   └── run_full_agency.ps1
└── active_brief.md                   # Auto-generated brief
```

**Note on Brief Generator:** The `brief-generator` skill is an optional pre-step. If you do not want to manually write `active_brief.md`, you can point this skill at your local Git repository. It will inspect your codebase architecture and auto-generate the active brief artifact for the rest of the swarm to consume. Trigger this by running `make extract` before running `make run`.

## 📦 Output Artifacts & Previews

Each agent writes a concrete deliverable into the workspace root and automatically adds it to your `.gitignore`:

1. `active_brief.md`: The synthesized product parameters (manual or auto-generated by Agent 00).
2. `01_competitor_matrix.md`: Pricing traps, Reddit/G2 complaints, and incumbent moats.
3. `02_gtm_strategy.md`: Positioning wedge, value anchors, and anti-positioning rules.
4. Launch pack files:
   - `landing_page.md`: Hero, feature transformation, and objection FAQ copy.
   - `show_hn.md`: Technical, authentic launch pitch.
   - `x_thread.md`: High-signal 5-tweet sequence.

## 🔌 Workflows & Skill Execution

This project provides unified workflows to execute the entire swarm sequentially, or you can invoke each skill individually.

- **Full Agency Run (Shell/PowerShell)**
  `bash workflows/run_full_agency.sh`
  `.\workflows\run_full_agency.ps1`
  
- **Individual Skill Invocation (Antigravity CLI)**
  You can use `agy` to run any skill individually while working on your code:
  `agy -p "Run the launch-copy skill based on our current strategy."`

## 🤝 Contributing & Extending

We welcome PRs to make this pipeline even more robust!
- **Add New Skills:** Create a new folder under `skills/` with a `SKILL.md` file following the strict markdown schema.
- **Add Workflows:** Create new orchestration scripts in the `workflows/` folder.
- **Add Brief Templates:** Need a template for an iOS app or B2B Marketplace? Add it to `context/templates/`.
